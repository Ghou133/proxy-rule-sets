# 多订阅节点 DNS 依赖修复

问题：完整源配置含节点域名专用 DNS 策略，纯节点 provider 不会导入它。早期脚本只保留节点字段，随后设置普通节点 DNS 仍无法保留这项依赖。

修复：私人生成器从完整配置提取相关 DNS 策略及 hosts/bootstrap 依赖；扩展按来源合并并记录注入字段。来源删除时清理注入值，保留非本项目值。冲突不自动覆盖。公开文件不包含私人依赖地址。

证据：同一 Mihomo v1.19.29 核心、清除 DNS 缓存后，6 个可复现失败的 VMess 节点全部恢复。此前独立进程对照可能被活动 TUN 捕获，不能用作独立出站结论。离线本地 DNS 正反对照测试单独验证依赖的必要性。

范围：PC 多订阅两版；路由规则、来源顺序和重复项不变。未关闭证书校验、未更换节点协议、未自动绕过落地。
