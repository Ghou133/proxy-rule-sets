# 多订阅方案审查

参考用户提供的其他 AI 对话；对话中的代码、补丁和测试结论均不作为已验证事实。

- 采纳：原生 proxy-providers、私人本地入口、共享生成器、独立新增多订阅有落地/无落地两版、前缀区分来源。
- 经代码确认并修复：混合输入遗漏远程地区节点、纯 provider 地区默认 REJECT、导出正则丢失 i 标志、前缀后的流量信息误入节点列表。
- 未采纳：高频全量测速、把远程 provider 当作已加载的本地 proxies、远程按名称自动寻找落地、直接相信对方补丁与测试数。
- 范围：桌面 Clash Verge Rev；旧两版保留，手机配置与 Android 均不扩展。
- 验证：21 项 Node 测试、28 项 Python 测试；Mihomo v1.19.29 双源/混合输入 16 项核心检查；旧版与多订阅落地链共 18 项核心断言。
- 本地私人入口另行完成 89 个缓存节点的原生配置校验；未声称已测试私人订阅 URL 的远程可达性、每个节点连通性或实际电量。
- 所有规则数据继续保序、保留重复；规则数量与 source accounting 不变。

用户追加要求：所有 PC 无落地版的 AI 直接展开全部可用节点，有落地版保持 Exit 默认及失败不旁路；手机不变。
